AstroScore readable

Which hours are worth going out for, drawn as the same grid as open-meteo_readable.html with a 觀星 score on top. Dark sky, moon low or down, few clouds — nothing else. The variables are fixed, so the only things to set are the place, how far ahead to look, and any extra parameters; all four forecast models come back in every request and the 雲量來源 tabs pick which one the grid is drawn from. Scroll the grid sideways for later hours. No API key needed. Variable names and model ids come from the Open-Meteo API docs.

觀星 = 0   if 太陽 > −10° — daylight or bright twilight is out, whatever the sky looks like 月亮扣分 = min(100, max(0, 月亮 / 10 × 100))   0 at or below the horizon, 100 from +10° up 觀星 = (100 − 雲量) × (100 − 月亮扣分) / 100   otherwise
雲量 20, 月亮 −5° → (100−20) × (100−0) / 100 = 80 moon down, near enough a clear night
雲量 20, 月亮  +2° → (100−20) × (100−20) / 100 = 64 low moon costs a fifth, not the hour
雲量 20, 月亮  +8° → (100−20) × (100−80) / 100 = 16 almost gone
雲量 20, 月亮 +10° → (100−20) × (100−100) / 100 = 0 moon high enough to write off
  • 月亮扣分 is altitude only — a crescent and a full moon at the same height score alike, so read the 月相 row alongside it.
  • 雲量 is total cloud cover from whichever model the 雲量來源 tabs have selected; the deck rows below are for context and do not enter the score. Switching tab redraws every row from that model — and rescores 觀星 with it — without another request, since all four came back together. Where two models tell the same story the forecast is worth trusting, and where they do not, it is not. jma_seamless publishes no precipitation_probability, so 降雨 is a row of dashes on that tab.
  • 銀心 is the altitude of the Milky Way core (Sgr A*, RA 17h45m, Dec −29°), up only part of the night. It does not enter the score — a dark clear hour is worth going out for either way — but below roughly +25° the core is shot through too much airmass to photograph, so read it beside a high 觀星 before packing for the core.
  • 銀心 (max) is the ceiling that row is measured against: how high the core gets at this latitude when it crosses the meridian, which is 90° − |緯度 − (−29°)| — fixed by the location, so the same number in every column, and untinted for that reason. Taiwan runs about +36° in Taipei to +39° at 墾丁: the further south, the higher the core rides. It is a ceiling, not a forecast — the core reaches it once a day whether or not the sun is down, so a whole night can pass with 銀心 well short of it.
  • 光害 (SQM) is how bright the sky itself is at the zenith, in mag/arcsec² — bigger is darker, and it is fixed by where you stand, not by the hour, so it fills every column with one number. It comes from David Lorenz's World Atlas of Artificial Night Sky Brightness (modelled from NOAA/VIIRS satellite data by the Earth Observation Group), the one light-pollution source that needs no API key. It is modelled, not measured, on a ~0.9 km grid. Not a score input: 觀星 rates tonight's sky, and no forecast can move the city.
  • Bortle and LP Zone are two labels for that same number, shown under it rather than instead of it. LP Zone is the atlas's own banding; Bortle is the familiar 1–9 scale, read off SQM by the conventional ladder — a rule of thumb the atlas's author pointedly declines to publish, since Bortle judges the whole sky (light domes on the horizon included) and a zenith figure cannot see them. It is also coarse exactly where it matters: Bortle 4 spans 21.69 down to 20.49, so most decent sites in Taiwan read "4" while LP Zone still tells them apart. Read the SQM.
  • The 太陽/月亮/月相/銀心 rows are computed from the location with this page's own astronomy, not read from the response — Open-Meteo returns only sunrise/sunset and a daily moon_phase, neither of which is an hourly altitude. They are the same Meeus series milkyway.py uses, and they are what the score above is built on.
