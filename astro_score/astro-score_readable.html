AstroScore readable

Which hours are worth going out for, drawn as the same grid as open-meteo_readable.html with a 觀星 score on top. Dark sky, moon low or down, few clouds — nothing else. The variables, the model and the extra parameters are fixed, so the only things to set are the place and how far ahead to look. Scroll the grid sideways for later hours. No API key needed. Variable names and model ids come from the Open-Meteo API docs.

觀星 = 0   if 太陽 > −10° — daylight or bright twilight is out, whatever the sky looks like 月亮扣分 = min(100, max(0, 月亮 / 10 × 100))   0 at or below the horizon, 100 from +10° up 觀星 = (100 − 雲量) × (100 − 月亮扣分) / 100   otherwise
雲量 20, 月亮 −5° → (100−20) × (100−0) / 100 = 80 moon down, near enough a clear night
雲量 20, 月亮  +2° → (100−20) × (100−20) / 100 = 64 low moon costs a fifth, not the hour
雲量 20, 月亮  +8° → (100−20) × (100−80) / 100 = 16 almost gone
雲量 20, 月亮 +10° → (100−20) × (100−100) / 100 = 0 moon high enough to write off
  • 月亮扣分 is altitude only — a crescent and a full moon at the same height score alike, so read the 月相 row alongside it.
  • 雲量 is total cloud cover from icon_global; the deck rows below are for context and do not enter the score.
  • 銀心 is the altitude of the Milky Way core (Sgr A*, RA 17h45m, Dec −29°), which from Taiwan peaks near +37° and is up only part of the night. It does not enter the score — a dark clear hour is worth going out for either way — but below roughly +25° the core is shot through too much airmass to photograph, so read it beside a high 觀星 before packing for the core.
  • The 太陽/月亮/月相/銀心 rows are computed from the location with this page's own astronomy, not read from the response — Open-Meteo returns only sunrise/sunset and a daily moon_phase, neither of which is an hourly altitude. They are the same Meeus series milkyway.py uses, and they are what the score above is built on.
