osrm_travel_time

Driving time from one lat,lon to every saved spot in places.js, in one request to the public OSRM /table service. No API key needed. OpenStreetMap roads at modelled free-flow speed: no live traffic, and mountain roads tend to come out optimistic. The demo server is fair-use only (about 1 request a second, no uptime promise), so each Fetch is one call.
